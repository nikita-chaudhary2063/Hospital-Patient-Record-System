# Hospital Patient Record System

A Python-based mini-project designed to manage hospital patient records using object-oriented programming and file handling.

## Features
- Add and store patient information.
- Display patient records.
- Manage patient details using classes and objects.
- Apply encapsulation to organize and protect patient data.
- Save records to a file for future access.
- Read saved patient records when the program runs.

## Concepts Practiced
- Classes and objects
- Constructors (`__init__()`)
- Encapsulation
- Public, protected, and private attributes
- Getters, setters, and `@property`
- File handling (`open()`, `read()`, `write()`)
- Input validation and error handling
